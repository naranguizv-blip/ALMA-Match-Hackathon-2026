Este catálogo permite revisar el alcance multiaisapre del inventario de trabajo de agosto de 2026. Es exploratorio: todavía faltan confirmaciones contractuales y comerciales de cada ficha.

No son 20 recomendaciones listas para contratar. Aquí se muestran códigos reales de inventarios previos, pero el motor de ALMA no los recomienda hasta verificar PDF, comercialización, porcentajes, topes de urgencia, prótesis, órtesis, modalidad de prestadores, precio base, GES y factores.

Los datos fueron seleccionados de inventarios operativos existentes. Los PDFs de terceros y la propuesta privada de un cliente no se incluyen en el repositorio. La referencia a un precio base de Consalud no constituye una prima final.
