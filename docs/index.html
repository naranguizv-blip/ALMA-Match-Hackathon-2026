¿Dónde interviene Meta AI?

El backend contiene la integración con Muse Spark 1.3 para analizar PDFs y devolver coberturas, redes, topes y referencias documentales. La lectura auténtica de un contrato se comprobó en una prueba técnica separada. Esta página estática no envía archivos a Meta ni simula que la IA está respondiendo en vivo.

Ver prueba de Muse Spark en GitHub
Alcance del prototipo: el caso real contiene tarifas de una propuesta comercial pasada. Los precios actuales, convenios, topes específicos y equivalencia contractual requieren validación adicional. La carga de un PDF desconocido requiere un servidor de análisis con Meta habilitado; no funciona desde una página HTML estática.
